# Writing content

Create one subfolder in this directory for each article. Use a short, URL-friendly folder name, then keep the article and all of its supporting files together:

```text
article-name/
├── article.md
├── metadata.json
└── assets/
```

- `article.md` contains the article in Markdown.
- `metadata.json` contains the article's `title`, `subtitle`, and `preview` text.
- `assets/` contains images, downloads, or other files used by that article.

Copy `example-article/` when starting a new piece, rename the copied folder, and replace the sample content.
